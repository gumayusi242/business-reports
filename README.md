# 业务报表

此仓库保存个人项目的公开脱敏源码包。

## 下载和运行

1. 下载 `business-reports-source.zip` 并解压。
2. 进入解压后的 `business-reports` 文件夹。
3. 按其中的 `README.md` 启动演示。

源码包内包含完整的本次脱敏源码与合成数据。未包含真实业务数据、配置凭据、原始 Git 历史、依赖目录及构建产物。具体替换内容见 [脱敏说明](PUBLIC_DEMO.md)。

## 本地启动

```sh
python demo_server.py
```


访问 http://127.0.0.1:6812/ 。离线预览涵盖主看板；未提供虚拟接口的深入分析、写入和同步功能会明确提示不可用。数据库适配器未连接生产数据。
